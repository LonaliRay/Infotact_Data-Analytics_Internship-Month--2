# Infotact Data Analytics Internship

## 📌 Overview

This repository contains the projects completed as part of my **Data Analytics Internship at Infotact Solutions**.

The internship provided hands-on experience in data cleaning, transformation, analysis, data visualization, and dashboard development using **Power BI, Power Query, and DAX**.

## 📂 Projects

### 📊 Month 1 – Multi-Touch Attribution & ROI Analysis

This project focuses on analyzing marketing touchpoints and understanding their contribution to conversions and return on investment (ROI).

**Key areas covered:**
- Multi-touch attribution analysis
- Marketing channel performance
- Conversion analysis
- ROI analysis
- Campaign and touchpoint insights
- Interactive Power BI dashboard

**Tools:** Power BI | Power Query | DAX

---

### 👥 Month 2 – E-commerce and Customer Value (CLTV) Analysis

---

This project focuses on analyzing customer purchasing behavior and customer value using Brazilian e-commerce transaction data.

**Key areas covered:**
- Customer value analysis
- High-value and premium customer segments
- Payment behavior
- Order volume by state
- Customer review analysis
- Geographic analysis
- Interactive Power BI dashboard

**Dataset:** Brazilian E-Commerce Public Dataset by Olist

**Tools:** Power BI | Power Query | DAX
